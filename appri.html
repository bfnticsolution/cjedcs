Bienvenue

Vous allez suivre une formation pratique de 20 heures sur 7 jours. À la fin, vous aurez créé et publié votre propre site web. Cette fiche vous accompagne : elle résume le programme, les consignes et vous permet de suivre votre progression.

Règle d'or : ne jamais copier-coller du code sans le lire. Comprendre ce qu'on écrit est plus important que la vitesse.

Rappel : les 6 réflexes à retenir

  1. Enregistrer souvent — Ctrl+S après chaque modification
  2. Vérifier le nom du fichier — majuscules et minuscules comptent
  3. Utiliser F12 dans le navigateur — pour voir le code source et les erreurs
  4. Ne jamais utiliser de chemin absolu — images/photo.jpg ✓ pas C:\Users\...\photo.jpg ✗
  5. Lire avant de coller — comprendre chaque ligne de code
  6. Poser une question sans hésiter — il n'y a pas de question bête
